Game Clicker V1

Meu primeiro projeto desenvolvido em JavaScript puro.

Um jogo simples de cliques onde o jogador acumula pontos, compra melhorias e utiliza power ups para aumentar sua produção.

Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

Funcionalidades

- Sistema de cliques
- Contador de pontos
- Melhorias de clique
- Sistema de níveis das melhorias
- Power Ups temporários
- Sistema de compra
- Botões com estados:
  - Comprável
  - Não comprável
  - Indisponível
- Menu de debug para testes

Objetivo do projeto

Esse projeto foi desenvolvido para praticar conceitos de JavaScript, principalmente:

- Manipulação do DOM
- Eventos
- Funções
- Objetos
- Arrays
- Laços de repetição
- Organização de lógica de jogo

Aprendizados

Durante o desenvolvimento aprendi a criar sistemas utilizando objetos e arrays para evitar repetição de código, além de trabalhar melhor com atualização de elementos HTML através do JavaScript.
